# iPAS 淨零碳規劃管理師（初級）單機離線模擬考 App

一款**單機、離線、零後端**的 iPAS 淨零碳規劃管理師（初級）證照備考 Web App。純 HTML / CSS / JavaScript，無建置流程、無 CDN，所有資料內嵌於本機檔案，可安裝為桌面 / 手機主畫面 PWA。

## 功能

- **每日模擬考**：每日抽考 10 題，當日不重複，可中途離開續作；交卷後可「考我更多」。
- **自動批改與解析**：逐題檢討，顯示正解與**解析**，並可跳至相關學習單元。
- **學習記憶曲線（SRS）**：答錯題自動進入複習排程、優先再現；連續答對逐步拉長複習間隔（1→3→約 7→約 15 天）。
- **學習模組**：兩考科、四單元完整教材，含**必背重點**、**關鍵名詞中英對照卡**、**重點表格**與**核心觀念區塊**；支援全文搜尋與已讀標記。
- **錯題本**：自動蒐集答錯題，可只練錯題、標記已掌握。
- **進度備份**：進度存於本機瀏覽器（localStorage），可匯出 / 匯入 JSON 跨裝置手動搬移。

## 題庫

共 **405 題**：
- 考古題 **200 題**：115 年第一次（05/16）、第二次（08/15）兩梯次、兩考科公告試題。附官方正解；**解析由模型依兩份官方學習指引（114 年版）教材撰寫，力求有據、不虛構**。
- 單元練習題 **185 題**：擷取自官方學習指引各單元「考題練習／考題解析」，**附官方解析**。
- 自編題 **20 題**：針對教材著墨較少但重要的考點補強，含解析。

> ⚠️ 說明：115 年第二次試題中少數題目涉及教材（114 年版）出版後的新事件或修正法規（例如 COP29／COP30、IFRS S1/S2、CBAM 2026 新制等）。此類題目之解析係依公認規範與領域知識保守撰寫，並於解析中審慎措辭；建議對照最新官方資料覆核。

## 使用方式

- **線上**：開啟 GitHub Pages 網址即可使用；可從瀏覽器「加入主畫面 / 安裝」為 App，之後離線可用。
- **本機**：直接以瀏覽器開啟 `index.html` 即可（離線）。

## 技術

- 單檔式離線 PWA：vanilla HTML/CSS/JS，無建置步驟、無外部相依。
- `data/questions.js`：題庫；`data/learning_content.js`：學習教材。
- `js/store.js`：進度儲存與 SM-2 記憶曲線引擎；`js/app.js`：UI、路由、抽題與批改。
- `sw.js`：Service Worker 快取，完全離線。更新內容時請將 `CACHE` 版本號 +1。
